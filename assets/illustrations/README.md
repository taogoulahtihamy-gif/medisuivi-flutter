# Illustration MediSuivi

`care_continuity.svg` est une composition vectorielle originale créée pour cette refonte : dossier, tracé décoratif et continuité du suivi. Aucun élément graphique tiers, police externe ou portrait n'est utilisé. Elle est livrée avec le code du projet, sans dépendance réseau. Le tracé est décoratif et ne représente aucune donnée clinique.

`medical_care.svg` est la ressource préexistante, conservée mais non utilisée par le nouvel accueil ; sa provenance n'a pas été établie pendant cette refonte.
